# Linux System Report Script

Мой первый Bash-скрипт для автоматического сбора информации о системе.

## Что делает скрипт
- Показывает текущую дату и время
- Выводит информацию о свободной оперативной памяти
- Показывает использование дискового пространства
- Отображает загрузку системы (uptime)

## Как использовать
1. Сделать скрипт исполняемым:
   ```bash
   chmod +x sysreport.sh
